The numbers on each card in the editor (1, 2, 3...) are not in the JSON HubSpot sends. This adds each card's number as a uiNumber field, so an AI or a teammate can say "action 12" and mean the card you see on screen. Numbers shift when actions are added, moved, or removed: they are valid for this capture only. actionId is the stable handle.

A segment names the lists it depends on (IN_LIST, association, suppression) by id only. HubSpot's page also loads their full definitions, and this bundles those captured responses into the export as one _related key, next to the segment. Every embedded body is byte-for-byte as HubSpot sent it, and deleting that one key restores the export without it, exactly.

Inserts an _aiContext block as the first key of the export: what this file is, when it was captured, and how to name actions (uiNumber for the card on the canvas, actionId as the stable handle). Still valid JSON, and it works with trimming on or off. Delete that one key and the remaining bytes are exactly the export without it.
